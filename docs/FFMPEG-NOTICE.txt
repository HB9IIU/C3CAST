FFmpeg in the C3CAST portable package
=====================================

ffmpeg.exe (tools/ffmpeg/bin) is a separate command-line program that C3CAST starts as a helper. It is NOT part of C3CAST's
own code and is not covered by C3CAST's licence. It is the only ffmpeg C3CAST uses: it encodes what you transmit, and it
re-encodes the pictures of the receivers to H.264 so that a web browser can play them.

  Encoders used by C3CAST: libx264 (H.264, only for the browser receivers), libx265 and hevc_nvenc (H.265), libvvenc (H.266,
  experimental) and the native aac (AAC-LC).
  Also built in: FreeType, HarfBuzz and Fontconfig (callsign text on the picture), zlib, bzip2, liblzma, libiconv and the
  NVIDIA ffnvcodec headers. Nothing else: no SRT, no Intel oneVPL, no SDL2, no hardware decoders.
  Compiled with GCC 16.2.0 (MSYS2 / media-autobuild_suite) on 4 November 2026. The exact configure line is in buildconf.txt.
