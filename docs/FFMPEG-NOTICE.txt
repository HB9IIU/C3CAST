FFmpeg in the C3CAST portable package
=====================================

ffmpeg.exe (tools/ffmpeg/bin) is a separate command-line program that C3CAST starts as a helper. It is NOT part of C3CAST's
own code and is not covered by C3CAST's licence.

What is in this build
  FFmpeg N-128191-g2602f39f5   commit 2602f39f55468b3c5ca9a2bf40f86ef8bcefad98   (unmodified)   https://ffmpeg.org
  x265   4.3-83-g83ce412       commit 83ce412fd71cf2eec56bbf07ba1de1aa74228953   (unmodified)   https://www.x265.org
  VVenC  v1.14.0-314-g1817b1e  commit 1817b1eb8a3d01a952922cb78bfa398ad3a6b087   (unmodified)   https://github.com/fraunhoferhhi/vvenc
  Encoders used by C3CAST: libx265 and hevc_nvenc (H.265), libvvenc (H.266, experimental) and the native aac (AAC-LC).
  Also built in: FreeType, HarfBuzz and Fontconfig (callsign text on the picture), zlib, bzip2, liblzma, libiconv and the
  NVIDIA ffnvcodec headers. Nothing else: no SRT, no Intel oneVPL, no SDL2, no hardware decoders.
  Compiled with GCC 16.2.0 (MSYS2 / media-autobuild_suite) on 29 October 2026. The exact configure line is in buildconf.txt.
