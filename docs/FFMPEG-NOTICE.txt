FFmpeg in the C3CAST portable package
=====================================

The portable package contains ffmpeg.exe and ffprobe.exe (tools/ffmpeg/bin). They are separate command-line programs
that C3CAST starts as child processes. They are NOT part of C3CAST's own code and are not covered by C3CAST's licence.

  The build uses --enable-gpl (libx265) and does not use --enable-nonfree, --enable-version3 or FDK AAC.
  FFmpeg's own licence information: FFmpeg-LGPL-2.1.txt and https://ffmpeg.org/legal.html

What is in this build
  FFmpeg   N-128097-g46f23be8b (git commit 46f23be8b, unmodified)    https://ffmpeg.org
  x265     4.3+73-g5143a2a (git commit 5143a2a, one local build patch)  https://www.x265.org
  Encoders used by C3CAST: libx265 (software H.265), hevc_nvenc (NVIDIA GPU H.265), native aac (AAC-LC).
  Also linked: FreeType, HarfBuzz, Fontconfig, zlib, bzip2, liblzma, libiconv and the NVIDIA ffnvcodec headers, each under its own licence.
  Compiled with GCC 16.2.0 (MSYS2/MABS). Full configure line: buildconf.txt in this folder.

Corresponding source (GPL)

  an upstream link staying available:

  Releases: https://github.com/HB9IIU/C3CAST/releases
