# C3CAST 1.0.0 release validation

Status: portable build accepted by the user on 2026-11-04. Source/provenance audit closed on 2026-11-04 (see below).

## Automated validation

- Source unit/regression suite: 60 tests passed.
- TX spectrum and automatic RX1 monitoring: passed with simulated inputs, no RF.
- Single-window/instance ownership: passed with replay video, no RF.
- Portable application and two concurrent H.264/H.265/H.266 receiver workers: passed. Includes header audio, enlarged popup, desktop/mobile, lost-signal recovery and normal shutdown. Tested from an independent temporary folder with spaces; the test PC still has Python installed.
- Firmware: unchanged binary payloads; package metadata updated to 1.0.0. No flashing during preparation.
- Package inspection passed: no private config, receiver settings/logs or private test artwork. All 32 bundled receiver/media binary checksums matched the inventory; existing source ZIP files passed integrity checks. See v1.0.0-components.json.

## Source/provenance audit: closed

Every program and library in the package has a licence and, where the licence asks for it, its source inside the package.
`tools/package_inventory.py` checks this on the finished package and writes v1.0.0-components.json (path, size, SHA-256, licence,
source file and licence text for each of them).

- **One ffmpeg.** The receivers use the same ffmpeg as the transmitter (tools/ffmpeg, GPL, built with x264, x265, VVenC, native AAC).
  A ready-made third-party receive build, used in an earlier draft, was removed because its corresponding source could not be supplied.
  Source of ffmpeg, x264, x265 (with its one build patch) and VVenC, the build script and settings, and checksums are in tools/ffmpeg/source.
- **DATVision programs** (datvrx.exe, rtl_iq.exe) and the native libraries next to them are byte-for-byte those of DATVision 1.0.0.
  The programs' source is in _internal/receiver/source/DATVision-1.0.0-source.zip. datvrx has no outside Rust libraries; rtl_iq uses only
  the C++ standard library and librtlsdr. librtlsdr (GPL v2+) and libusb 1.0.28 (LGPL) come with their source; winpthreads (MIT) with its text.
- **C# tuner service:** its source is in _internal/receiver/tuner-service/src. libusb 1.0.27 and LibUsbDotNet 2.2.29 (LGPL) come with their
  source; Json.NET (MIT), Serilog (Apache 2.0) and the .NET support libraries with their texts. FTDI's .NET wrapper is closed source and FTDI
  allows its distribution with its licence text unmodified (included); the FTDI driver itself is not shipped.
- **H.266 Player:** its source, the exact source of its ffplay and the libraries it shares with the tuner service are in H266-Player/source.
- **Python side:** the packages inside C3CAST.exe are listed with their licences in _internal/sources/PYTHON-PACKAGES.txt, their licence
  texts are in _internal/sources/licenses, and esptool (GPL v2+) comes with its source.

## User hardware acceptance

On 2026-11-04 the user reported the portable build working and approved the
repository update. The supplied screenshot (docs/screenshot.png) shows version
1.0.0, board connected, and two MiniTiouners locked simultaneously on different
signals. Earlier live testing in this session also demonstrated RTL-SDR reception.
No firmware or transmitter behavior changed in this release preparation.

The following is the broader hardware test matrix; the screenshot does not prove
every item or every symbol-rate/FEC combination:


- Fresh portable launch, board detection and settings saved across restart.
- Short low-level TX and clean Stop/PTT release; source changes and supported FEC/SR.
- Real simultaneous receivers, including RTL-SDR; both tune to beacon at startup.
- RX1 tunes to actual TX downlink/SR; RX2 remains unchanged.
- Popup playback/audio, signal loss/return, tuner contention and retry.
- Duplicate tab/app protection and normal shutdown release all receiver handles.
- Windows machine without Python/project tools and an extraction path with spaces.

The user has accepted the functional hardware test. Publishing the binary release is the owner's decision.
