# C3CAST 1.0.1 release validation

Status: package built; the checks below say what was and was not done.

## Automated validation

- Source unit/regression suite: 82 tests passed. The tests no longer read or write the developer's own config.json.
- Real FFmpeg checks (no camera, no RF): the picture overlay runs in all eight combinations of banner, scrolling text and UTC/local time;
  the Detect audio delay recording command produced the file, the live picture and the sound level with OBS Virtual Camera and a VB-Audio cable.
- OBS Virtual Camera with a VB-Audio cable, 10 s into a file: 0 decoded video frames before the fix, 274 after it (285 with the "Auto" silence input).

## Source/provenance audit

Unchanged from 1.0.0: the same programs, libraries, sources and licences are in the package. `tools/package_inventory.py` is run on the
finished package and writes v1.0.1-components.json.

## User acceptance

The user tested the changes on the running source version on 2026-11-10 with a Logitech C920, OBS Virtual Camera, MiniTiouner and
PicoTuner and reported being satisfied. The packaged application was extracted from the zip into a folder with spaces and started on its own: it answers, shows v1.0.1, has the new Setup
options, starts as a fresh install (placeholder callsign) and carries no config from the developer's PC. No firmware or
transmitter behaviour changed in this release. Publishing the binary release is the owner's decision.
