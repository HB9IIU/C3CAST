Firmware images flashed by the C3CAST web app (Flash button).

Built from this project's src/ (PlatformIO, ESP-IDF 6.1.0): SP8ESA's ESP32-DATV firmware, upstream commit 915e62d,
with the PTT/PA output moved from GPIO3 to GPIO10 (D10). Regenerate with tools/export_firmware.py after a build.
