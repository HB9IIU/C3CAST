Python packages inside C3CAST.exe
================================

C3CAST.exe is a Python program packed with PyInstaller. These are the packages it is built from, with the licence each one declares.
Where a package keeps a licence file, it is in the folder _internal\<package>.dist-info\ of the package folder.

The only package with a source obligation is esptool (flashing the board), GPL v2 or later:
  esptool-5.6.0.tar.gz   its exact source, in this folder (the official sdist from PyPI).
C3CAST starts esptool as a separate helper process (C3CAST.exe --worker esptool) and does not modify it.

Python itself (PSF licence): Python-PSF-LICENSE.txt in this folder.
The PyInstaller bootloader (GPL v2 with an exception for the programs it packs) is used under that exception.
